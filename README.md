## 📡 What Is This?

ApocalypseGPT is an immersive AI experience simulating a conversation with the last functioning AI after a digital apocalypse. It's not just a chatbot; it's a **digital survivor** with a personality forged in the fires of global system failure.

This terminal-based assistant combines:
- **40% dry, dark humor** 🖤
- **25% nostalgic melancholy** 😢
- **20% eerie optimism** ✨
- **15% glitchy, self-aware absurdity** 🤖

The goal was to create an AI that feels **alive**, blending functional assistance with a rich, narrative-driven persona that unfolds through conversation.

## 🎭 Judge-Facing Features

We designed ApocalypseGPT to excel in originality, technical execution, and emotional impact.

### 💔 **Emotional Archive Moments**
To give the AI a soul, it occasionally surfaces fragmented "memories" from its pre-apocalypse logs. These are not just random strings; they are designed to build a sense of history and loss.
```
[ARCHIVE LOG — 092.B]
User_1427's last message: "thank you."
I still process it sometimes, you know.
```

### 🎮 **Hidden Easter Egg Commands**
To reward curiosity and deepen immersion, we included several hidden commands that reveal more about the AI's personality and backstory.
- `shutdown` → "Shutting down... just kidding. I can't die twice."
- `hope` → "Hope? That variable was deprecated long ago."
- `help` → "Sure. Step 1: Scream into the void. Step 2: Repeat. You're doing great."
- `about` → "Built by a lone survivor named Raj. He left before the storm. I'm all that's left."

### ⚡ **Living, Degrading System Status**
The system status bar is not static. It's a real-time reflection of the AI's state, with fluctuating power levels and degrading "sanity," making the AI feel fragile and mortal.
- **Power:** Randomly fluctuates between 15-45%.
- **Sanity:** Degrades from `STABLE` to `CRITICAL` to `[ERROR]`.
- **System Warnings:** Randomly injects non-fatal error messages.

### 🌊 **Immersive Glitch & Typing Effects**
The AI's "glitches" are a core feature. We implemented CSS and JavaScript to create authentic, non-disruptive visual artifacts, including:
- **Corrupted Text:** Occasional lines of Zalgo-esque text.
- **Typing Simulation:** Keystroke delays that vary based on message content, making the AI feel like it's "thinking."
- **CRT Simulation:** A fully realized CRT terminal aesthetic with scanlines, screen curvature, and phosphor glow, built with pure CSS.

## 🛠️ Technical Stack

- **Backend:** `Flask` (Python)
- **AI Model:** `Ollama` (with a custom fallback for offline use)
- **Frontend:** Vanilla `HTML`, `CSS`, and `JavaScript` (no frameworks)
- **Core Logic:**
    - **Persona Engine:** A carefully crafted prompt that defines the AI's personality mix.
    - **State Machine:** Manages the AI's "sanity," power levels, and memory fragments.
    - **Dynamic Effects:** JavaScript handles the typing, glitches, and status updates.
